# Spectral Fingerprints of Neutron Displacement Response

## Code and Data Repository

This repository contains the Python code and datasets accompanying the manuscript:

> **Spectral Fingerprints of Neutron Displacement Response Revealed by Interpretable Machine Learning**

## Overview

Neutron displacement cross-section (DXS) spectra provide valuable information about radiation damage in materials. This project presents an interpretable machine-learning framework for predicting an integrated displacement-response metric from physics-informed spectral descriptors extracted from IAEA DXS data.

The study compares Random Forest and multilayer perceptron (MLP) models, evaluates predictive performance using leave-one-out cross-validation (LOOCV), and investigates feature importance through permutation importance and statistical analyses.

## Data

The original neutron displacement cross-section (DXS) data are publicly available from the **IAEA Nuclear Data Services**.

This repository includes the final machine-learning dataset used in this study:

- `ml_dataset_v8.csv`

Additional feature tables included in this repository are:

- `material_features.csv`
- `material_damage_features.csv`

The intermediate processed dataset (`dxs_master_dataset_all_v2_clean.csv`) is generated from the original IAEA DXS files using the preprocessing scripts provided in the `src/` directory and can be regenerated by users following the workflow.

## Reproducing the Results

To reproduce the analysis:

1. Download the original neutron displacement cross-section data from the IAEA Nuclear Data Services.
2. Parse and merge the DXS files.
3. Perform quality control.
4. Generate material descriptors and the machine-learning dataset.
5. Train the Random Forest and MLP models.
6. Perform statistical validation.
7. Generate the figures reported in the manuscript.
